Pasta para imagens personalizadas dos slides.
Formato esperado:
slide-01.png (ou .jpg)
slide-02.png (ou .jpg)
...
slide-12.png (ou .jpg)

A apresentação carrega as imagens automaticamente ao iniciar ou trocar de slide.
Se a imagem não existir, a apresentação exibe automaticamente a ilustração SVG correspondente com design profissional integrado.
